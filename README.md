 📊 HR Analytics Dashboard – Power BI

## 📌 Project Overview

This project is an interactive **HR Analytics Dashboard** created using Power BI to analyze employee workforce data and explore patterns related to employee attrition, departments, salary slabs, job roles, satisfaction levels, demographics, and experience.

The project demonstrates the use of **Power Query, DAX, and Power BI data visualization** to transform raw employee records into an interactive HR analytics report.

---

## 🎯 Project Objectives

The dashboard was designed to analyze:

- Total employees
- Active employees
- Employee attrition
- Attrition rate
- Department-wise attrition
- Salary-wise attrition
- Job role and satisfaction levels
- Age-group distribution
- Gender-wise attrition
- Experience-based trends

---

## 🔄 Project Workflow

### 1. Data Preparation

Imported the employee dataset into Power BI and prepared the data for analysis.

### 2. Data Cleaning

Used Power Query to:

- Handle null values
- Remove duplicate records
- Standardize inconsistent text values
- Correct data types
- Prepare the dataset for analysis

### 3. DAX Calculations

Created measures for key HR metrics including:

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate %

### 4. Dashboard Development

Created interactive Power BI visualizations to analyze employee attrition and workforce characteristics.
